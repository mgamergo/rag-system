Ingest

  1. Decode selected .md/.txt files strictly as UTF-8.
  2. Validate config and normalize BOM/newlines.
  3. Reserve a document/run using SHA-256 content/config keys; reuse duplicates.
  4. Split into code-point windows and optionally generate Anthropic context per chunk with prefix caching.
  5. Embed context plus original text through the chosen hosted provider.
  6. Write bounded chunk/vector batches, then atomically activate the run.

Ask

  1. Create a running trace, then validate question/config.
  2. Load an immutable, paginated selected corpus; enforce model compatibility for semantic/hybrid.
  3. Run exact semantic cosine, BM25, TF-IDF or equal-weight RRF hybrid.
  4. Optionally rerank candidateK sources down to topK. Alternatively reconstruct full documents without retrieval.
  5. Send the original grounded prompt with separate generated context. Reject output truncation.
  6. Save a success/failure trace and display evidence with filename, index, offsets and score.

Re-embed

Read stored original chunks/context. Stage new vectors and switch their active run only on success. Keep chunk IDs and the original chunk run. Export active chunks/vectors as JSONL.

Evaluate

Parse gold JSONL, validate labels against the selected snapshot, then run each method/k configuration through the existing retrieval evaluator. Persist dataset, config, corpus versions, aggregate metrics and per-query results. No answer generation occurs. Download reports from /evals.

Failure boundaries

Provider calls have explicit timeouts and no automatic retries. Failed writes/inference do not activate staged runs. Hard action termination can leave indexing/running records requiring future recovery tooling.
