From documents to grounded answers

First, convert documents into searchable chunks. Later, turn a question into a search, retrieve the matching text, and give that evidence to the answer model. Follow arrows downward; the dashed arrow connects storage to retrieval.

Select any step for the exact code location. On narrow screens, scroll the diagram sideways.

What to understand as you read
  • Chunk: a small excerpt of original text, with offsets identifying its position.
  • Embedding: a numeric representation used to search for related meaning. It is not an answer or a text summary.
  • Retrieval: selecting stored excerpts. The generation model receives the retrieved text, not the numeric vectors.
  • Two separate implementations: the web app does not call the TypeScript package. Their storage, defaults, and available retrieval methods differ.
  • Learning order: upload handler → ingest action → storage/schema → ask action → vector search → generation → answer UI. Then explore the TypeScript alternatives.
